LinkTool User Manual

Getting Started: Downloading Your First Pack

This manual will guide you through downloading a data pack from your Psion Organiser II to an OPK file usingthe LinkTool web application.

What You'll Need

  • Psion Organiser II with a data pack installed (Pack B or Pack C)
  • Serial adapter (USB-to-serial or native serial port)
  • Serial cable connected between your computer and the Psion Organiser II Comms Link
  • Compatible web browser (Chrome 89+, Edge 89+, or Opera 75+)
NOTE
Firefox and Safari do not currently support the Web Serial API required by this tool.

Step-by-Step Guide

1. Prepare Your Hardware

  1. Connect your Psion Organiser II to your computer using the serial adapter and Comms Link cable
  2. Ensure the Psion Organiser II is powered on
  3. Open the LinkTool web application in your browser

2. Select the Pack to Download

Before connecting, choose which pack you want to download:

  • Click the "Slot" selection button to toggle between Slot B: andSlot C:
  • The default selection is Slot B:
  • The button will display your current selection
TIP
If you're unsure which slot contains your data, start with Slot B: as it's the most commonly used.

3. Initiate the Connection

  1. Click the "Connect" button in the web application
  2. Your browser will display a serial port selection dialog
  3. Select the COM port corresponding to your serial adapter
  4. Click "Connect" in the browser dialog
IMPORTANT
Make sure you select the correct COM port. If you're unsure, check your Device Manager (Windows) or systemsettings to identify the serial adapter's port.

4. Start the Download on Your Psion Organiser II

Once connected, you need to initiate the transfer from the Psion Organiser II:

  1. On your Psion Organiser II, navigate to the main menu
  2. Select COMMS
  3. Select BOOT
  4. Select NAME (leave it blank - no name is required)
  5. Press the appropriate key to confirm

The Psion Organiser II will now wait for the boot injection from your computer.

5. Monitor the Download Progress

The LinkTool will automatically:

  1. Inject boot code into the Psion Organiser II's RAM
  2. Transfer the pack data from the selected pack
  3. Display real-time progress in the communication log
  4. Show a progress indicator as data is received

You'll see messages in the log window showing:

  • Boot injection progress (Pairs 0-6)
  • Data transfer phases (HEADER and BODY)
  • CRC verification results
  • Completion status
NOTE
The download process typically takes 1-3 minutes depending on the pack size. Do not disconnect or power offthe Psion Organiser II during this process.

6. Save Your OPK File

Once the download completes:

  1. The "Save Pack" button will become enabled
  2. Click "Save Pack" to download the OPK file to your computer
  3. Your browser will prompt you to save the file (default name: pack_b.opk orpack_c.opk)
  4. Choose a location and save the file
TIP
Give your OPK file a descriptive name to help you identify its contents later (e.g.,my_contacts_2026.opk).

7. Disconnect

After saving your OPK file:

  1. Click the "Disconnect" button to release the serial port
  2. You can now safely disconnect the serial cable from your Psion Organiser II

Writing Data to a Pack (Pack Download)

This section will guide you through writing (or flashing) an OPK file from your computer onto a physical data pack in your Psion Organiser II using the LinkTool web application.

What You'll Need

  • Psion Organiser II with the COMMS Link installed in the Top Slot
  • Writable Data Pack (a blank Flashpak, RamPack, or UV-erased Datapak) in Slot B or Slot C
  • Power Supply: Recommended (Mains power adapter or fresh 9V battery)
  • Serial connection: USB-to-serial adapter and Comms Link cable connected to your computer
  • Compatible web browser: Chrome 89+, Edge 89+, or Opera 75+
TIP: WHICH PACKS CAN BE WRITTEN?
You can write to Flashpaks, RamPacks, and blank UV Datapaks:
  • Flashpaks & RamPacks: Can be formatted and rewritten electronically directly by the tool.
  • UV EPROM Datapaks: Must already be blank (erased under a UV lamp window) before writing. They cannot be erased electronically by software.

Step-by-Step Guide to Writing a Pack

1. Prepare Your Hardware

  1. Power off the Psion Organiser II.
  2. Firmly insert the COMMS Link into the Top Slot.
  3. Connect the serial cable between your computer's USB serial adapter and the Comms Link.
  4. Recommended: Plug a mains power adapter into the COMMS Link or ensure the Organiser has a fresh 9V battery. (Writing to packs uses extra power to program the memory).
  5. Insert your blank data pack into Slot B (the upper side slot) or Slot C (the lower side slot). You can insert it now, or wait until the tool prompts you on screen.
  6. Turn the Organiser ON.
  7. Open the LinkTool web application in your browser.
IMPORTANT
Always use a reliable power source when writing packs. If the battery runs low during writing, the transfer may fail.

2. Switch to Write Mode and Select Your OPK File

Before connecting, select Write mode and choose the file you want to put on your pack:

  1. Click the "R/W Toggle" button to switch from Read to Write mode. The button will display Mode: WRITE.
  2. Click the "Select File" button. A file window will open on your computer.
  3. Select the .OPK file you wish to write and click Open.
  4. The tool will check your file and display the file name and size in the log (for example: Insert a blank 16 K byte Data Pack into slot B: to write MyFile.OPK to).
  5. Click the "Slot" selection button to choose Slot B: or Slot C: to match the slot where you inserted your blank pack.
TIP
Make sure the slot selected on the button (Slot B: or Slot C:) matches the physical slot where your blank pack is inserted.

3. Prepare the Psion Organiser II

Important: Just like when reading a pack, prepare your Psion Organiser II before connecting in the web tool:

  1. On your Psion Organiser II, navigate to the main menu.
  2. Select COMMS.
  3. Select BOOT.
  4. Navigate to NAME: (leave it blank - no name is required).
  5. Stop here — do not press EXE yet!
IMPORTANT
The tool has a limited time window to connect after you press EXE. By navigating to the NAME: prompt first, you will be ready to press EXE immediately after the tool starts searching for the device.

4. Connect and Start the Transfer

Now that your Psion Organiser II is waiting at the NAME: prompt:

  1. Click the green "Connect" button in the web application.
  2. Your browser will display a serial port selection window.
  3. Select the COM port corresponding to your serial adapter and click "Connect".
  4. Wait for the tool to display "Searching for Device..." in the status area.
  5. Now press EXE on your Psion Organiser II to start communication.

The tool will immediately connect to your Organiser and prepare it for writing.

TIP
If you see a timeout error, simply click Disconnect, return to the NAME: prompt on the Organiser, and try again.

5. Insert Blank Pack and Confirm

Once the initial connection is made, a confirmation window will appear on your screen:

Example Dialog Prompt:

"Insert a blank 16 K byte Data Pack into slot B: to write MyFile.OPK to.
Click Continue to begin the download phase."

  1. Make sure your blank data pack is firmly inserted into the chosen slot.
  2. Take your time: the tool automatically keeps the connection alive while this window is open, so there is no rush!
  3. Click the green "Continue" button, or simply press Enter or Space on your keyboard.
TIP
If you changed your mind or need to cancel, click the "Cancel" button (or press Escape) to safely abort without modifying your pack.

6. Formatting and Writing Progress

The LinkTool will now handle the entire write process automatically:

  1. Formatting: The tool will first format the pack to prepare its memory. This takes only 2 to 3 seconds for Flashpaks and RamPacks, or up to 60 seconds for larger UV packs.
  2. Writing: The tool will then stream your OPK file data onto the pack. Each block is automatically checked and verified as it is written.
  3. Progress Tracking: You can watch the live progress bar and percentage display as data is written.
NOTE
The writing process typically takes 1 to 3 minutes depending on the file size. Do not unplug cables, remove the pack, or turn off the Organiser while writing is taking place.

7. Finalization and Disconnect

When the writing is finished:

  1. The tool will finalize the pack directory so your Organiser can immediately recognize all files.
  2. The status will display "Download Complete! Pack written successfully!".
  3. The tool will automatically release the connection, and your Psion Organiser II will return safely to WAITING FOR LINK or its main menu.
  4. Click the "Disconnect" button if it is still enabled.
  5. You can now safely remove your freshly written pack or turn off your Organiser II!
TIP
You can now test your new pack! Turn your Organiser II on, navigate to your main menu, and look at your newly written files.

What is an OPK File?

An OPK file is a binary image of a Psion Organiser II data pack. It contains:

  • Magic header (OPK!) identifying the file format
  • Length field indicating the size of the pack data
  • Pack data (the actual contents of your data pack)
  • Terminator marking the end of the file

OPK files can be viewed and edited using the OPK Editor tool, which allows you to:

  • Inspect the raw contents of the pack
  • View and modify individual records
  • Analyze the pack structure
  • Export data in various formats

Troubleshooting

Connection Issues

Problem: Browser doesn't show any serial ports
  • Solution: Ensure your serial adapter is properly connected and drivers areinstalled
  • Check Device Manager (Windows) to verify the adapter is recognized
Problem: "Failed to open serial port" error
  • Solution: The port may be in use by another application. Close any terminalprogramsor other applications using the serial port

Transfer Issues

Problem: Download stalls or times out
  • Solution:
    • Check the serial cable connections
    • Ensure the Psion Organiser II is in the COMMS BOOT menu
    • Try disconnecting and reconnecting
    • Verify the correct pack is selected
Problem: CRC errors in the log
  • Solution:
    • This may indicate communication errors
    • Try reducing electrical interference near the cable
    • Ensure the serial cable is in good condition
    • The tool will automatically retry failed transfers

Psion Organiser II Issues

Problem: Psion shows "TRAP" error
  • Solution:
    • This may indicate a timing issue or buffer misalignment
    • Reset the Psion Organiser II and try again
    • Ensure you're using the correct boot sequence (COMMS → BOOT → NAME)
Problem: Psion displays "ABORT: CODE 241", "ABORT: CODE 246", or "ABORT: CODE 193"
  • Solution:
    • CODE 241 / 246 (NO PACK): The Organiser cannot detect a data pack in the chosen slot. Check that your pack is pushed firmly and all the way into Slot B or Slot C. Make sure the slot selected in LinkTool (Pack B or Pack C) matches where your pack is physically inserted. If needed, gently clean the pack's gold connector pins with a dry, soft cloth.
    • CODE 193: Communication error or low battery power. Make sure your serial cable is firmly plugged in and your Organiser has a fresh 9V battery or is connected to a mains power adapter.
Problem: Pack Writing pauses at the "Insert Blank Pack" window
  • Solution:
    • This window is designed to wait for you so that you have plenty of time to insert your pack. Once your pack is firmly seated in the slot, click the green "Continue" button, or press Enter or Space on your keyboard.
Problem: Organiser screen shows "WAITING FOR LINK" after writing
  • Solution:
    • This is completely normal! When writing is finished, the Organiser displays WAITING FOR LINK to show the session has concluded safely. Your pack is ready to use. You can safely disconnect the serial cable or press ON/CLEAR on the Organiser to return to your main menu.

Advanced Features

Debug Mode

For troubleshooting or protocol analysis, you can enable debug mode:

  1. Add ?debug=true to the end of the LinkTool URL
  2. Reload the page
  3. The communication log will show detailed protocol information including:
    • Raw packet data
    • Timing information
    • Detailed state transitions

Serial Port Settings

The LinkTool uses the following default serial parameters:

  • Baud rate: 9600
  • Data bits: 8
  • Parity: None
  • Stop bits: 1
  • Flow control: None

These settings match the Psion Organiser II Comms Link specifications and should not need adjustment.

Next Steps

After downloading your pack to an OPK file, you can:

  1. Back up your data by storing the OPK file in a safe location
  2. View the pack contents using the OPK Editor tool
  3. Transfer the pack to another Psion Organiser II by reversing the process (if supported)
  4. Archive multiple versions of your packs over time
  5. Verify the integrity of your packs over time using the check sums
