OPL & Emulation Guide

This emulator acts as a faithful 9-pin impact printer using the industry standard ESC/P control set.

Any system that outputs ASCII characters can print text directly via a serial link or web socket.
For graphics and custom characters, you can redefine fonts dynamically using ESC & or draw bit-images using ESC K (Draft/60 DPI), ESC L (120 DPI), or ESC Z (240 DPI).

See the EFX-80s companion app. in the repository for a custom ESC mode image encoder.

Help Reference

Getting Started

Connect your hardware or link the emulator using the CONSOLE tab. If using Web Serial, ensure baud rates match.

Use the CONSOLE text box to quickly test characters, or type escape sequences like \eE (Bold On) or \eF (Bold Off).

ESC/P Control Codes

The EFX-80 supports standard ESC/P commands:

  • ESC @ : Reset
  • ESC ! n : Master Select
  • ESC E / F : Bold On/Off
  • ESC 4 / 5 : Italic On/Off
  • ESC G / H : Double Strike On/Off
  • ESC - n : Underline On/Off
  • SI / DC2 : Condensed On/Off
  • ESC P / M : Pica / Elite Pitch
  • ESC 2 / 3 n : Set Line Spacing (1/6" / n/216")
  • ESC C n / 0 n : Page Length (Lines / Inches)
  • ESC N n / O : Skip-Over Perforations On/Off
  • ESC & : Download font character
  • ESC % n : User-defined Font On/Off
  • ESC : 0 0 0 : Copy ROM characters to RAM
  • ESC K/L/Y/Z : 8-Pin Bit Graphics (60/120/120-HS/240 DPI)
  • LF / CR / FF : Line Feed / Carriage Return / Form Feed
  • HT / CAN : Horizontal Tab / Cancel Line

Keyboard Shortcuts

Global emulator control hotkeys (when text fields are not focused):

  • F : Feed paper 3 lines
  • T : Tear off paper
  • M : Strip tractor margins
  • D : Run self-test diagnostics page
  • Delete : Clear paper roll & reset buffer
  • S : Save Printout (PNG)
  • C : Copy Printout (Image to Clipboard)
  • ↑ / ↓ : Scroll paper roll (24px steps)
  • W (Hold) + ↑ / ↓ : Micro-scrolling (1px step)

PC Connections

Classic serial devices may need custom wiring to connect the P.C. serial port connector.

If using custom connections you will need to connect at least the following PC COM port pins to the classic serial device (e.g. another classic P.C.):

  • 25 Way: pins 2, 3 & 7
  • or
  • 9 Way: pins 2, 3 & 5

Depending on the arrangement of the device being connected you may need 'a cross over' connection. e.g. pin 2 of one device is connected to pin 3 of the other device.

Note: A classic Organiser II COMMS/RS232 link is designed for direct connection to a 25 way D-Type COM port connection.

Hardware & Conflict Warnings

A serial COM port i.e. a Serial-to-USB convertor or internal serial COM port hardware can only be connected to one application on the host machine.

Connect your legacy serial device e.g. the Organiser's serial COMMS Link to the selected serial COM port or Serial-to-USB convertor on the host computer.

The browsers Web Serial will try to set the default baud rate settings. You may need to set your host computers serial port settings to match ( e.g. 9600 Baud, 8 Data Bits, No Parity, and 1 Stop Bit ).

Important: Ensure no other software (terminal programs, ORG-LINK or OPK transfers) is holding the serial port open, as standard P.C. port hardware can only be accessed by one app / program at a time.

WebSocket Support

The emulator can receive ESC/P print data over a WebSocket connection from any compatible server on your network — no Web Serial hardware required.

How to connect

Open the Controls panel and expand the WebSocket card. Set your server address, port and channel, then click Connect. ESC/P data sent by the server arrives directly at the printer parser.

URL format

ws://<host>:<port>/<channel>?clientId=<id>
  • host — hostname or IP address of your server
  • port — default 8080
  • channel — printer, plotter, or a custom path token
  • clientId — auto-generated; identifies this browser session

Accepted frame types

  • Binary — raw ESC/P bytes, piped directly to the parser
  • Text — UTF-8 string, treated as plain ESC/P text
  • JSON — control frame (must start with {):
    {"type":"lan-ip","ip":"192.168.x.x","port":8080}
    Updates the QR code display automatically.

Status indicators

  • CONNECTED — socket open, data flowing
  • DISCONNECTED — no active connection
  • LOCKED — server rejected with close code 4001; another client holds an exclusive channel lock
  • ERROR — connection refused or network fault

Secure connections (wss://)

Switch the scheme to wss:// when connecting through a Cloudflare Tunnel or any TLS endpoint. Required if this page is served over HTTPS.

The emulator is a WebSocket client only. It connects outward to your server — it does not host a server itself.

Node.js Test Server

This minimal Node.js script starts a WebSocket server on port 8080 and sends a formatted ESC/P test print job when the emulator connects.

Prerequisites

  • Node.js installed on your machine
  • Run once in a terminal: npm install ws
  • Then run: node ws-test.js
// ws-test.js — EFX-80s WebSocket test server
// Setup: npm install ws
// Run:   node ws-test.js

const http = require('http');
const { WebSocketServer } = require('ws');
const PORT = 8080;

const server = http.createServer((req, res) => {
    res.writeHead(200); res.end('WS test server on port ' + PORT);
});

const wss = new WebSocketServer({ server });

wss.on('connection', (ws, req) => {
    console.log('\n[+] Client connected  path: ' + req.url);

    const ESC = 0x1B, LF = 0x0A, FF = 0x0C;

    const job = Buffer.concat([
        Buffer.from([ESC, 0x40]),          // ESC @ — reset
        Buffer.from([ESC, 0x45]),          // ESC E — bold on
        Buffer.from('WebSocket Test Print\r\n'),
        Buffer.from([ESC, 0x46]),          // ESC F — bold off
        Buffer.from('ws://localhost:' + PORT + req.url + '\r\n'),
        Buffer.from(new Date().toISOString() + '\r\n'),
        Buffer.from([LF, LF, FF]),
    ]);

    setTimeout(() => {
        ws.send(job);
        console.log('[>] ESC/P job sent (' + job.length + ' bytes)');
    }, 400);

    ws.on('close', code => console.log('[-] Disconnected  code:' + code));
});

server.listen(PORT, () => {
    console.log('Listening on ws://localhost:' + PORT);
    console.log('Connect emulator: ws://localhost:' + PORT + '/printer\n');
});

Connect the emulator to ws://localhost:8080/printer — bold WebSocket Test Print should appear on the paper roll.
