Circular Chart Recorder Emulator

Modbus RTU — Real-time process variable emulation via Web Serial

Protocol & Usage Guide

This emulator acts as a faithful Modbus RTU slave device. Connect a Modbus RTU master (PLC, SCADA, or test tool) at 9600 baud, 8N1. The emulator responds to Function Codes 0x03, 0x06, and 0x10.
All process variables are held in a virtual 16-bit register bank. 32-bit IEEE 754 floats are stored across two consecutive holding registers (high word first).

Modbus RTU Frame Format

Each Modbus RTU frame ends with a CRC-16 (polynomial 0xA001). The slave only responds if its station address matches Byte 0.

  • Byte 0 : Station Address
  • Byte 1 : Function Code (03 / 06 / 10)
  • Byte 2–3 : Start Register Address (0-based)
  • Byte 4–5 : Quantity / Data Value
  • Byte N-1, N : CRC-16 Low, High

Frame delimiter: ≥3.5 character silences (~3.6 ms at 9600 baud), emulated here via a configurable inter-frame timeout.

PC Connection

Use a USB-to-RS485 or USB-to-RS232 adaptor to expose a COM port. Click Connect Serial in the CONTROLS panel and select the adaptor.

Match your master device baud rate. Default: 9600 baud, 8N1, no flow control.

Only one application may hold a serial port at a time. Close any terminal program before connecting here.

CRC-16 Engine

Modbus RTU CRC-16 uses polynomial 0xA001 (reflected form of 0x8005). The CRC covers all bytes except the CRC field itself.

Frames with an invalid CRC are silently discarded, exactly as real hardware behaves.

ASCII Protocol & OPL Guide

Simple ASCII Line Protocol Structure:

  • Read Query: $PV?\r\n or $01:PV?\r\n
    Returns: *PV:P1=25.00,P2=60.00,P3=110.00,P4=145.00\r\n
  • Write PVs: $P1=45.5,P2=80.2\r\n or $01:P1=50.0,P2=75.0,P3=120.0,P4=160.0\r\n
    Returns: *OK\r\n
  • Flow Control: Software XON (0x11) / XOFF (0x13) supported.

Organiser II OPL Code Example:

CHART:
  LOCAL p1,p2,cmd$(32)
  LOPEN "A"
  p1=45.5 : p2=80.2
  cmd$="$P1="+NUM$(p1,5,1)+",P2="+NUM$(p2,5,1)+CHR$(13)+CHR$(10)
  LPRINT cmd$
  LCLOSE

Getting Started

Open the CONTROLS panel, then click Connect Serial to pick your USB-serial adaptor. The emulator will immediately start listening for Modbus RTU or Simple ASCII frames.

Use the CONFIG panel to set the station address, engineering units, alarm thresholds, and chart speed before connecting a master.

Architecture

The emulator is split into three decoupled layers:

  • VirtualDevice — register bank & data model
  • ModbusParser — CRC-16, FC dispatch, response builder
  • SerialPort I/O — Web Serial read loop with inter-frame timeout

Warnings

Web Serial requires Chrome 89+ or Edge 89+. Firefox and Safari are not supported.

Only one application can hold a COM port. Ensure no other terminal or driver software has the port open.
