## Features  
*  **15-Parameter OPL LSET: Configurator & Engine**
*  **Interactive 3-Bit Handshake Selection Matrix**
*  **LSET: Command Workbench & Decompiler**
*  **17 Hardware Presets**
*  **Dynamic UART Frame Structure & Logic Waveform Visualisation**
*  **Cable Pinout Schematic & Connector Matrix**
*  **Quick-Start Guide & UI Controls**


<BR>

## Usage  
COMMSParam is a visual configuration workbench and frame simulator for serial communications on the Psion Organiser II (CM, XP, LZ, LZ64, POS series).

It calculates, formats, and decompiles the 15-parameter LSET: OPL statement and verifies physical RS-232 cable pinout wiring. 

<BR>

## Technical Details  

*   **Architecture**: Client-side JavaScript application
*   **Output Format**: Text commands for OPL and other programming languages
