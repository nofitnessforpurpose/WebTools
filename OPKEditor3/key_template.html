Browser & OS Hotkey Note

For Ctrl + Function keys to pass to the web application successfully, configuration adjustments may be needed:
  • macOS (Safari/Chrome/Firefox): Go to System Settings > Keyboard > Keyboard Shortcuts > Function Keys and turn on "Use F1, F2, etc. keys as standard function keys".
  • Chrome / Edge: If extension shortcuts override keys, manage/disable conflicting shortcuts at chrome://extensions/shortcuts.
  • Firefox: By default, Ctrl + F4 will close a tab. Users can configure overrides via advanced preferences (about:config) or install keyboard mapping helper extensions.

Printing Instructions:

1. Press Ctrl+P (or Cmd+P).

2. Set Layout to Landscape.

3. Ensure "Background Graphics" is checked/enabled.

4. Scale: 100% (Do not scale to fit) for accurate keyboard sizing.
