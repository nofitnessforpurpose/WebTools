Keyboard Shortcuts Reference

Platform & Configuration Notes:
• macOS Users: Use ⌘ Cmd instead of Ctrl, and ⌥ Option instead of Alt.
• Psion Function Keys (Ctrl + F1–F12): Require "Enable Psion Function Keys" enabled in Options > Visuals to prevent browser conflicts (e.g., F5 page reload). On macOS, enable "Use F1, F2, etc. keys as standard function keys" in macOS System Settings.
